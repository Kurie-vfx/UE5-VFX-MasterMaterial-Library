# UE5-VFX-MasterMaterial-Library
A versatile master material library for Unreal Engine 5, designed for VFX artists.
Designed for real-time VFX production workflows. Free for personal and commercial use.
VFXアーティスト向けに設計した、UE5の汎用的なマスターマテリアルライブラリです。商用利用可。

## Features
- Reusable and customizable master materials
- Material functions for VFX workflows
- Optimized for real-time effects
- Easy to integrate into projects

## 特徴
- 再利用可能でカスタマイズしやすいマスターマテリアル
- VFX向けマテリアル関数を収録
- リアルタイムエフェクト向けに最適化
- プロジェクトに簡単に導入可能

## How to Use
1. Download or clone this repository
2. Copy the Content folder into your UE5 project
3. Open the project and start using the materials

## 使い方
1. このリポジトリをダウンロードまたはクローン
2. ContentフォルダをUE5プロジェクトにコピー
3. マテリアルを利用開始
