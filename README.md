# UE5-VFX-MasterMaterial-Library
A versatile master material library for Unreal Engine 5, designed for VFX artists.
Designed for real-time VFX production workflows.
Free for personal and commercial use.
VFXアーティスト向けに設計した、UE5の汎用的なマスターマテリアルライブラリです。
商用利用可。

## 🧩Features / 特徴
- Reusable and customizable master materials / 再利用可能でカスタマイズしやすいマスターマテリアル
- Material functions for VFX workflows / VFX向けマテリアル関数を収録
- Optimized for real-time effects / リアルタイムエフェクト向けに最適化
- Easy to integrate into projects / プロジェクトに簡単に導入可能

## 🧩How to Use / 使い方
1. Download or clone this repository / このリポジトリをダウンロードまたはクローン
2. Copy the Content folder into your UE5 project / ContentフォルダをUE5プロジェクトにコピー
3. Open the project and start using the materials / マテリアルを利用開始

## 🧩Contents / 内容
- Materials
- Material Functions
- Textures
