# UE5 Kurie VFX Shader

**Kurie VFX Shader** is a pack of versatile master materials for UE5, designed to provide commonly used features for VFX production.  
[日本語はこちら](README_JP.md) 

<p align="center">
  <img width="80%" src="images/VFXSample01.gif" alt="Kurie VFX Shader">
</p>

## 🧩Features
- Reusable and easy-to-customize materials  
- Includes common functionality for VFX workflows  
- Comes with a sample map  
- Easy to use: simply download the ZIP and place it into your UE5 project  

## 🧩How to Use
For installation and usage instructions, please refer to the manual below.  
[UE5 Kurie VFX Shader Manual](https://zenn.dev/kurie/books/4e27d7a6dc84de)

## 🧩Features
- Flipbook  
- Multi-texture blending  
- Various UV controls  
- Soft particles  
- Fresnel  
- Dissolve  
- Refraction
